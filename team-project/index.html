Про проєкт

Kitty World - це командний проєкт з Web-програмування. Сайт створений як односторінковий каталог товарів для котиків у рожевому стилі.

У каталозі користувач може переглядати різні категорії товарів: ласощі, іграшки, бантики, будиночки, засоби догляду та аксесуари.

На сайті також є пошук, фільтр за категоріями, привітання користувача за іменем та аркадна гра Kitty Catch.

Для створення проєкту використано HTML, CSS, JavaScript та завантаження даних з JSON-файлу.
